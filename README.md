# Kumamoto Earthquake Disaster Governance (2026)

令和8年熊本地震（2026年7月28日発生）に関する災害ガバナンス研究のコード化データと分析資料を公開するためのリポジトリです。

## 研究概要

本研究では、熊本県災害対策本部会議の議事録、熊本県知事のコメント、およびKVOAD「火の国会議」の議事録を対象に、災害対応における行政機関と民間支援組織の役割、機能、相互補完関係を分析します。

関連論文：向井洋子「令和8年熊本地震に関する危機管理ガバナンス（仮）」、第25回都市水害に関するシンポジウム論文集、土木学会西部支部、2026年。  
※正式な論文題目および書誌情報は確定後に更新します。

## 公開データ

| ファイル | 内容 |
|---|---|
| `data/coded_units_public.csv` | 熊本県災害対策本部会議議事録765単位と知事コメント553単位、計1,318単位のコード化データ（本文を除く） |
| `data/kvoad_units_public.csv` | KVOAD「火の国会議」議事録のコード化データ2,183単位（本文を除き、一部の発言主体名を匿名化） |
| `data/mapping_governance_to_function_observed.csv` | 元のガバナンス分類と機能分類について、実際に観測された組み合わせと件数を示す集計表 |

分類基準や欠損値の扱いについては、codebook.md を参照してください。

なお、分類の対応関係を示す集計表は、実際に観測された組み合わせを示すものであり、必ずしも一対一の変換規則を意味するものではありません。

本リポジトリには、議事録や知事コメントの本文は収録していません。公開するのは研究のために作成した分類・コード化データです。

## 分析・検証

分析にはRを使用しています。解析環境は sessionInfo.txt、コーディングの一致度に関する検証データは validation/validation_public.csv、その再計算用Rコードは validate_agreement.R に収録しています。その他の分析コードについては、内容を確認したうえで順次追加する予定です。

検証対象131単位のうち、両者の分類結果が得られた118単位について、一致率は63.6％（75/118）、Cohenのκ係数は0.554でした。検証方法と解釈上の留意点は codebook.md を参照してください。
